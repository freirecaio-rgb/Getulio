# História de Getúlio Vargas

## Objetivo

Eu criei este site como um trabalho de Educação Digital do CAP-UEM. Meu objetivo é apresentar de forma simples e organizada alguns dos principais acontecimentos da história de Getúlio Vargas, utilizando HTML, CSS, JavaScript e p5.js.

## Parte autoral

Eu criei a estrutura do site, a organização das informações, a linha do tempo sobre Getúlio Vargas, o botão de Like com contador e a interação feita com p5.js. Também escolhi as cores e o visual do site, inspirado nas cores do Brasil.
